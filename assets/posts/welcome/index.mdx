### 2. 列表 (Lists)

#### 无序列表
- **高性能**：没有 GC，内存安全。
- **可靠性**：丰富的类型系统和所有权模型。
- **生产力**：优秀的文档和编译器。

#### 有序列表
1. 初始化项目：`cargo init`
2. 添加依赖：`cargo add dioxus`
3. 运行项目：`dx serve`

### 3. 代码块 (Code Blocks)

我们可以使用代码块来展示 Rust 代码：

```rust
use dioxus::prelude::*;

fn main() {
    dioxus::launch(App);
}

#[component]
fn App() -> Element {
    let count = use_signal(|| 0);

    rsx! {
        div { class: "flex flex-col items-center gap-4 p-8",
            h1 { "Hello, Dioxus!" }
            button { 
                onclick: move |_| count.set(count() + 1),
                "Count: {count}" 
            }
        }
    }
}
```
