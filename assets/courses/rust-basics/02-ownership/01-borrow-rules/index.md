# 借用规则（Borrow Checker 101）

Rust 的借用检查器在编译期强制执行如下规则：

- 同一作用域内可以有**任意数量**的不可变借用（`&T`）；
- 但只能有**唯一**一个可变借用（`&mut T`）；
- 可变借用与不可变借用**不能同时存在**。

```rust
fn main() {
    let mut v = vec![1, 2, 3];

    let r1 = &v;
    let r2 = &v;
    println!("{r1:?} / {r2:?}"); // 不可变借用：可以同时多个

    let m = &mut v;
    m.push(4);
    println!("{m:?}"); // 可变借用：必须唯一
}
```

> [!IMPORTANT]
> 借用规则不是限制你的"权力"，而是为你提供静态保证：编译通过即意味着不存在数据竞争。
