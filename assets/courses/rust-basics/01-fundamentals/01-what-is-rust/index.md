# 什么是 Rust

Rust 是一门系统编程语言，专注于**安全**、**并发**、**性能**三大目标。它在编译期通过所有权系统消除了一整类内存错误（数据竞争、空悬指针、缓冲区溢出），同时保留接近 C/C++ 的运行时开销。

## 三个核心承诺
1. **零成本抽象**：高级语法编译后与手写底层代码无差异。
2. **内存安全（无 GC）**：所有权 + 借用检查在编译期保证。
3. **无畏并发**：类型系统确保跨线程数据访问的正确性。

> [!TIP]
> 当你看到 `&` 与 `mut` 时，记住它们描述的是**借用关系**，而不是单纯的引用。

下面是一段最小例子：

```rust
fn main() {
    let greeting = String::from("Hello, Rust");
    println!("{greeting}");
}
```

后续课节会逐步展开所有权（Ownership）、借用（Borrowing）、生命周期（Lifetime）等概念。
