# 快速上手

欢迎来到 **Rust in Everything** 文档！本指南将帮助你快速了解如何使用本站的各项资源。

## 环境准备

1. 安装 Rust：`curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
2. 安装 Dioxus CLI：`cargo install dioxus-cli`
3. 克隆项目：`git clone https://github.com/example/rustineverything.app`

## 运行项目

```bash
dx serve
```

打开浏览器访问 `http://localhost:8080`。
